Sync between Laptop & Mobile devices

Why updated data doesn't automatically show on Mobile:

When you update data on your laptop browser, browsers store it locally in localStorage. GitHub Pages only serves the static standard file structure unless you update the default data inside the code itself!

1 Option A: Export Updated HTML for GitHub (Recommended)

Download a new index.html containing your existing tasks/locations/engineers as the default state. Upload this file to GitHub so all mobile devices display your updated data automatically upon opening!

2 Option B: Transfer via JSON Backup

Export data on laptop, then import the file or paste JSON on your mobile phone.
